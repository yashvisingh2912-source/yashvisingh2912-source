**Team Project · ML & RAG Lead**

**My contributions**

**Individual Project · Explainable ML**

A Streamlit-based awareness application that estimates PCOS risk from symptom-based and clinical inputs.

**What I built**
- Compared classification models and prioritized recall to reduce missed positive cases.
- Added SHAP-based explanations to communicate which features influenced predictions.
- Designed separate symptom-check and clinical-analysis workflows.
- Included an awareness-focused disclaimer to clarify the tool's limitations.

**Technologies:** Python · Pandas · Scikit-learn · SHAP · Streamlit
